# UNKNOWN

Protótipo inicial do jogo de mistério apresentado como um smartphone fictício.

## Versão 0.1

- Tela de bloqueio com relógio e gesto de deslizar.
- Tela inicial de celular.
- Barra de status e dock.
- Mensagens, Telefone, Galeria, Arquivos, Navegador, E-mail, Ajustes e Notas.
- Persistência local das notas.
- Base pronta para adicionar capítulos, pistas, escolhas e eventos condicionais.

## Estrutura

- index.html
- style.css
- script.js

O projeto é estático e pode ser aberto diretamente no navegador.
